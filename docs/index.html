Windows may show a SmartScreen warning because the installer is not code-signed. Choose “More info”, then “Run anyway”. Android may ask you to allow installations from this source.

Both apps check for updates. Already using an Android version older than 1.0.3? Read the installation guide before upgrading.

Neo Calendar also works with the Markdown files in your Obsidian vault; no separate Obsidian plugin download is needed.
