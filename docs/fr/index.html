Votre calendrier, vos fichiers. Retrouvez vos événements dans vos propres fichiers Markdown, sur Windows et Android.

Windows Voir les releases Android Voir les releases

Windows peut afficher un avertissement SmartScreen : l'installateur n'est pas signé. Cliquez sur « Informations complémentaires », puis « Exécuter quand même ». Android peut demander l'autorisation d'installer depuis cette source.

Les deux applications recherchent les mises à jour. Si vous utilisez Android dans une version antérieure à 1.0.3, consultez le guide d'installation avant de mettre à jour.

Neo Calendar fonctionne aussi avec les fichiers Markdown de votre coffre Obsidian : aucun plugin Obsidian séparé n'est nécessaire.
